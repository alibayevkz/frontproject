# Добровольная отправка геопозиции

Сайт на Flask. Геолокация определяется только после нажатия посетителем кнопки, отдельно показывается точность и координаты. Владелец увидит данные **только после явного подтверждения отправки**.

Возможности: HTTPS для доступа к GPS; закрытая панель `/inbox`, вход на `/login`, пароль из `DASHBOARD_PASSWORD`; результаты до 24 часов в оперативной памяти (могут пропасть раньше при перезапуске и без постоянного хранилища); лимиты на отправку; без сбора IP для панели.

Для Render: Python, build `pip install -r geo-share/requirements.txt`, start `cd geo-share && gunicorn app:app --bind 0.0.0.0:$PORT --workers 1 --threads 2`; в Environment добавить `DASHBOARD_PASSWORD`, `SESSION_SECRET`. HTTPS обязателен.

*Это краткосрочный вариант, не подходит для постоянного хранения.*
